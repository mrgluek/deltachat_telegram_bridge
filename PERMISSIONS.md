# Права доступа (Permissions)

Актуально для версии 2.38.0. Модель прав одинакова для Telegram и Delta Chat и описана ниже. Ключевое правило: **владелец управляет всем, суб-админ только тем, что создал сам**.

## Роли

| Роль | Telegram | Delta Chat |
|------|----------|------------|
| **Владелец** | `admin_tg_id` (числовой ID) | `/initadmin` или `set_admin.py`. Если задан отпечаток ключа (`admin_dc_fingerprint`), владелец опознаётся **только по ключу**: адрес почты не сравнивается вообще. Только если отпечатка нет (старая настройка «только по почте»), работает сравнение по адресу. |
| **Суб-админ** | `/adminadd <id или @username>` (@username бот находит через юзербот) | `/subadminadd <email>` или карточка контакта с подписью `/subadminadd`. Опознаётся **только по отпечатку ключа**. |
| **Все остальные** | обычный пользователь | обычный пользователь |

Telegram-суб-админ и DC-суб-админ — разные записи. Бот не знает, что это один человек: каждый видит и снимает только то, что создал на своей стороне (в TG записан ID пользователя, в DC — отпечаток ключа).

**Публичный режим** — владелец не задан. Тогда `/bridge` и `/unbridge` доступны администраторам группы, а команды управления ботом, каналами и фильтрами недоступны никому.

## Принятая модель доверия

- Кто добавил бота в Telegram-группу, тот может её привязать. Знание ID группы или приватного канала считается достаточным основанием: проверки «состоит ли суб-админ в этой группе» нет.
- Исключение: суб-админ **не может** привязать Telegram-группу, у которой уже есть мост. Добавить к ней ещё одну DC-группу может только владелец.
- Юзербот читает только то, что нужно мостам: каналы и группы, подключённые командами владельца или суб-админов.

## Мосты групп

| Действие | Telegram | Delta Chat |
|----------|----------|------------|
| `/bridge` | владелец, суб-админ (в публичном режиме: админ TG-группы). Создаёт DC-группу и выдаёт ссылку. | владелец, DC-суб-админ (в публичном режиме: создатель DC-группы). Требует ID Telegram-группы. Не-владелец не может привязать уже привязанную TG-группу. |
| `/unbridge` | владелец: все пары чата. Суб-админ: только пары, которые создал сам. | то же |
| `/invite`, `/inviteqr` | владелец: все мосты группы. Суб-админ: только свои. В публичном режиме: админ группы. | — |
| `/stats` | в личке: владелец видит все, суб-админ только свои. В группе: владелец, создатель моста, админ группы. | в личке: владелец все, суб-админ только свои. В группе: статистика этой группы. |

## Каналы (TG → DC)

| Действие | Кто | Примечание |
|----------|-----|-----------|
| `/channeladd`, `/channelremove`, `/channels` | владелец и суб-админы (TG: в личке с ботом; DC: в личке и в группах) | Суб-админ видит и снимает только свои каналы. В публичном режиме и без владельца управление каналами закрыто. |
| `/channels` в DC | все видят публичные каналы; владелец в личке видит все; суб-админ в личке видит публичные и свои | |
| `/channelN`, `/channelNqr` (ссылка для подписки) | публичный канал: любой. Приватный: **только владелец или создатель, и только в личном чате с ботом**. | В группе бот отвечает «Ask for this invite in a private chat» без ссылки. `/channeladd` приватного источника из группы присылает ссылку только в личку. |

## Только владелец

`/status`, `/botsend`, `/userbotjoin`, `/userbotsync`, `/catchup`, `/cleanup`, `/locupdate`, `/channelssync`, `/filters`, `/filteradd`, `/filterdel`, `/transports`, `/addtransport`, `/rmtransport`, `/richmode`, `/adminadd`, `/adminremove`, `/admins`, `/subadminadd`, `/subadminremove`, `/subadmins`.

`/initadmin` в Delta Chat работает только пока не задан ни DC-владелец, ни `admin_tg_id`, и только в личном чате.

## Ссылки t.me в Delta Chat (превью постов)

Любой пользователь может прислать боту ссылку `https://t.me/<канал>/<номер>`. Юзербот читает такое сообщение только если это **канал или супергруппа**. Диалоги с людьми и ботами не читаются. Исключение: подключённый к мосту бот, и только если ссылку прислал владелец (такие ответы не кэшируются). Дополнительно для превью действует лимит: 5 запросов на отправителя в минуту.

## Данные в уведомлениях владельцу

Если ключ владельца задан и бот не находит контакт с этим ключом, уведомления и коды входа юзербота **не отправляются** (на другой ключ с тем же адресом они не уходят).
